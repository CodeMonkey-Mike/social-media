## Careful (easy to get wrong on camera)

1. **"Agents for Amazon Bedrock" is the old thing, and it is closed to new customers.** AWS now calls it "Amazon Bedrock Agents Classic" and says it "will no longer be open to new customers starting on July 30, 2026"; AWS recommends AgentCore instead. Say "Amazon Bedrock AgentCore", never "Bedrock Agents". Source: https://docs.aws.amazon.com/bedrock/latest/userguide/agents-classic-maintenance-mode.html
2. **AgentCore GA vs preview.** Core platform GA Oct 13, 2025. Policy and Evaluations were preview at re:Invent 2025 (Dec 2, 2025), GA in March 2026. Harness GA June 2026. Browser Web Bot Auth is still only confirmed as preview. Nova 2 Omni only confirmed as preview.
3. **Nova Canvas is gone.** It reached end of life Sep 30, 2026. Do not show it as the image-model answer. Stability models (Stable Image Core / Ultra, SD 3.5 Large) are active on Bedrock, in us-west-2.
4. **Lambda's 15-minute limit is out of date.** The Lambda quota page now says 30 minutes (90 on Lambda Managed Instances). BUT Remotion's own docs still say Remotion Lambda renders must fit in 15 minutes, so for Remotion say "Remotion caps each render at 15 minutes", not "Lambda caps at 15 minutes".
5. **The 8-hour limit is per microVM session.** AgentCore Runtime Instances (EC2 in your account) allow up to 14 days. The default idle timeout is 15 minutes, so a long-running agent must report `HealthyBusy`.
6. **A human gate longer than 8 hours does not fit inside one AgentCore session.** For an overnight approval the graph must checkpoint (AgentCoreMemorySaver / DynamoDBSaver / Postgres) and resume in a new session, or the wait lives in a Step Functions Standard workflow (up to one year). Express workflows cannot wait for a callback at all.
7. **Step Functions to AgentCore is Request Response only and 15 minutes per Task state** (`invokeHarness`). It cannot wait on an agent run for hours.
8. **AgentCore Browser is 1 vCPU / 4 GB per session**, 1000 concurrent sessions per account by default. Its price is per vCPU-hour and GB-hour, not per session.
9. **Two Runtime price sets exist** (microVMs v1 and v2). Name which one you quote. The v2 CPU price on the page has no dollar sign (0.1276).
10. **Claude model names on Bedrock** must match AWS's list (e.g. "Claude Opus 5.5", "Claude Sonnet 4.6"). Bare model ID in-Region only in London for Opus 5.5; everywhere else use `us.` / `eu.` / `global.` inference profile IDs.
11. **Claude Code on Bedrock has no WebSearch tool.** Any agent that relies on WebSearch (for example a research agent) needs another search tool (AgentCore has a Web Search tool, $7.00 per 1,000 queries, limited regions).
12. **"Claude Platform on AWS" is a different thing from Bedrock** (`CLAUDE_CODE_USE_ANTHROPIC_AWS=1`). Do not mix the two names.
13. **X-Ray SDKs are in maintenance mode** (since Feb 25, 2026; end of support Feb 25, 2027). Say "OpenTelemetry into CloudWatch (X-Ray / Transaction Search)", not "add the X-Ray SDK".
14. **Region limits.** AgentCore Memory and harness are in fewer regions than Runtime. Stable Image Core is us-west-2 only. Pick one region on screen (us-east-1 or us-west-2) and keep it consistent.
15. **Transcribe price is flat now.** The Price List API shows one rate, $0.006 per minute in us-east-1 (no tiers). Older articles quote $0.024 per minute tiers: do not use them.
16. **MediaConvert bills normalized output minutes**, so "per minute" depends on resolution, fps and codec; quote one named profile (e.g. HD AVC up to 30 fps, single pass, Pro tier, $0.024 per minute in us-east-1).
17. **Fargate has no GPU.** Whisper on GPU means EC2 (G5 / G6 / G6e), AWS Batch on EC2, SageMaker AI, or AgentCore Runtime Instances (GPU-accelerated), not Fargate.
18. **Remotion Lambda concurrency cap is Remotion's own (200 functions)**, separate from the AWS account limit (1,000 concurrent Lambda executions by default).
