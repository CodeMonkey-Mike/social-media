Chapter 2

Two Kinds of Harness

  • The agent harness runs the loop and hands the model its tools
  • The evaluation harness hands out the tasks and grades the output
  • You never grade the model alone. You grade it with its harness
  • Harness engineering: everything you build around the model
Chapter 3

The Pipeline and the Graph

  • A livestream fans out into 3 lanes. Lane 2 is the clips
  • One LangGraph graph owns all 3 lanes: 14 steps, 2 human gates
  • 6 agents inside it: 3 make judgment calls, 3 build or check
Chapter 4

How the Harness Holds an Agent

  • Spawn: a step runs its agent headless, output to a log file
  • Retry: once on an overload, once on the next model down
  • Trust the artifact: the plan has to exist on disk as JSON
  • Validate: a failed plan stops the run before a frame gets cut
Chapter 5

Rules in Code, Not in the Prompt

  • The shape of a clip plan: in the validator
  • Where files may go: in a hook, every turn and every commit
  • The model fallback: in the spawner, with a script that proves it
  • "Done": checked by the last step of the graph
Chapter 6

State and Memory

  • The agents remember nothing. Every run starts fresh
  • The harness holds the state: SQLite checkpoints, files, docs
  • A human gate is a LangGraph interrupt: stop now, resume later
Chapter 7

What Was Missing

  • 3 graders already ran: code-based, model-based and human
  • Each one judged a single run. My verdicts were thrown away
  • The fix has 3 parts: a record, a replay, a score
Chapter 8

What Changed in the Repo

  • Outside the graph: a module of around 1,000 lines and its tests
  • Inside the graph: small on purpose, 86 lines added
  • An eval layer should watch production, not be woven through it
Chapter 9

Recording a Verdict

  • One new call at the gate records every verdict
  • If the record can't be written, the batch keeps going
  • Every clip gets a line: kept or killed
  • The file is append-only, and it's committed to Git
Chapter 10

The Prompt Version

  • A hash of 4 things: 3 files and the instruction text
  • Change any one of them and you get a new 12 character version
  • Stamped when the plan passes validation, never at the gate
Chapter 11

Recall

  • Precision: of the clips it proposed, how many did I keep?
  • No recall from a gate: it only sees what was proposed
  • So when I approve the gate, I name what it missed
Chapter 12

Replay

  • A replay: the same transcript with today's prompt
  • Nothing gets cut and nothing gets posted
  • The same instructions a live run sends, plus a note
  • The note's last line: don't open the evals folder
Chapter 13

Matching and Scoring

  • A match: the overlap is at least 50% of the shorter clip
  • 4 buckets for a new pick: kept, killed, missed, or new
  • Precision: good picks over good picks plus repeated kills
Chapter 14

Noise

  • The same prompt, twice, on 4 livestreams
  • 2 scored the same. 2 went from 100% to 83.3%
  • On one livestream, a swing of around 17 points is noise
