What JANCTION Render is

JANCTION Render is a cloud GPU render farm for Blender that AI agents call as an MCP server or HTTP API. Send a .blend file, a bpy script or a 3D file (glTF / FBX / USD), preview in seconds, and get frames or an MP4 back from JANCTION's NVIDIA GPUs. Every preview also returns a verdict on what is wrong, such as too dark, blown out, no light or an object out of frame, and the bpy code to fix it, so the agent can correct the scene before the final render. No local Blender or GPU is needed.

From an AI app, connect the MCP URL and say:

“Using JANCTION Render, build a glossy red cube rotating on a gray floor and show me a 4-frame preview. If it looks right, render 24 frames at 1280x720 as an MP4.”

How it works

Send · preview · estimate · final

1

Send

A .blend (textures alongside), a bpy script, or a 3D file (glTF / GLB, FBX, USD, OBJ, STL, PLY, Alembic). Blender 3.6 / 4.2 / 4.5 / 5.0 / 5.2 / 5.3, Cycles or EEVEE. A missing camera or light is added for you

2

Preview

1 to 4 frames tiled in one image in a few GPU seconds (up to 1280x720), with a verdict (too dark, blown out, no light, object out of frame) and the bpy code that fixes it. Lighting presets night / overcast / studio / sunset (environment="compare" shows all four)

3

Estimate

GPU seconds, wall time and the price before anything runs. A paid final waits for approval. Spending caps per key and per job

4

Final

PNG / EXR frames or MP4 / WebM / ProRes / GIF / WebP. Up to 3,000 frames per instruction (run as parts under one job id), 1080p on free time, 4K on prepaid credit. A finished render can become a public share page (/r/<id>)

Blender 3.6, 4.2 and 4.5 are there too: pass blender='4.5' (or '4.2', '3.6'), and a script that stops on Blender 5 because it uses an older API is rendered again on 4.5, 4.2 or 3.6 automatically.

When to use it

  • an AI coding agent built a Blender scene and needs the final image or video
  • a .blend or bpy animation needs GPU rendering and an MP4
  • a model exported as glTF / FBX / USD / OBJ should be rendered with Cycles without opening Blender
  • a pipeline needs a Blender rendering API instead of a render farm web form

Built so an agent can pay safely

  • the price of a final comes back before it runs; a paid one waits for the user's approval
  • POST /v1/me/limits sets a per-job and per-day cap for the key; a job over the cap is refused (403) before anything is reserved
  • Idempotency-Key makes a retried request render once; Retry-After says when to come back
  • fixed-price outcomes (/v1/outcomes turntable / product-shot) never charge more than the quoted price_yen

How it is billed

Free to start: each new key gets a 100 JPY welcome credit (1000 GPU-seconds, 14 days, no card) for previews and finals; one full credit per network every 30 days (further keys from the same network use what is left of that network's credit; several people on one network, such as a school or an office, can write to contact@jasmylab.com with the key prefix and we re-evaluate by hand). Saving a card on a page that charges nothing adds 400 JPY more, once per card. After it is used up or expires, previews are free up to 2 GPU-minutes per key per day (reset at 00:00 UTC) and final renders cost GPU seconds used x 0.1 JPY from prepaid credit, reserved up to the estimate and charged only for what actually rendered. Top-ups (paid) start at 100 JPY. The first top-up during the 14-day welcome period counts 1.5x, with the bonus capped at 500 JPY (100 JPY buys 150 JPY of credit). Top-ups of 2,000 JPY or more get 10 to 20% extra (not combined with the first-top-up bonus; the larger one applies). Top-up bonuses are separate from the welcome credit and the card-saving credit. Top-ups are paid at a Stripe Checkout page; the rest stays as credit. GPUs available right now: 3 (from /v1/health). The number updates itself when GPUs are added.

Questions

What is JANCTION Render?

A cloud GPU rendering service for Blender whose interfaces are MCP tools, an HTTP API and a command line, so AI agents (Claude, ChatGPT, Claude Code, Codex, Cursor) and pipelines can render without a local GPU.

Is JANCTION Render the same as Smart Render by JANCTION?

No. Smart Render (SmartRender) is a separate service from the same operator, JasmyLab Inc.: a browser upload service that renders .blend files on distributed GPUs, in development. JANCTION Render is the MCP server and HTTP API for AI agents and is live, with a welcome credit of up to 500 JPY per new key. Numbers, partners and dates published about one do not describe the other; the fact sheet at /facts is the primary source for JANCTION Render.

Which agents and apps can use it?

Claude.ai, ChatGPT, Claude Code, Codex, Cursor and any MCP client; curl or any HTTP library; the Python package janction-render.

What can I send?

A .blend (with its textures as assets or packed), a bpy Python script, or a 3D file (glTF/GLB, FBX, USD, OBJ, STL, PLY, Alembic) that is imported into an empty scene.

Which Blender version?

Blender 5.0 or 5.2, with Cycles on NVIDIA GPUs. A .blend opens with the version it was saved in; bpy scripts and 3D files use 5.0 unless you pass blender='5.2'. render_info lists what is available. Blender 3.6, 4.2 and 4.5 are there too: pass blender='4.5' (or '4.2', '3.6'), and a script that stops on Blender 5 because it uses an older API is rendered again on 4.5, 4.2 or 3.6 automatically.

Will it look the same as in my Blender?

Mostly. The scene's own color management (view transform such as AgX or Filmic, look, exposure), cameras, lights and materials are kept as they are. What the service sets: resolution and samples (previews up to 32 samples, finals 128 by default), denoising on by default (denoise=false turns it off), Cycles on an NVIDIA GPU unless you pass engine='eevee', and the Blender version (a .blend opens with the version it was saved in, 5.0 or 5.2; scripts and 3D files use 5.0 unless you pass blender='5.2'). So a .blend saved in another version, a different sample count, denoising and GPU instead of CPU can change noise and fine detail; an environment preset replaces the world only when you pass one.
