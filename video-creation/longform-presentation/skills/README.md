# longform-presentation/skills

**Per-track skills for the 16:9 presentation / screen-share track.** ONE FOLDER PER SKILL (Mike, 2026-09-28,
mirroring `video-creation/skills/` and `longform-edited/skills/`): the folder is named after the skill, the doc is
`<name>/<name>.md`, and every script that belongs to it lives inside. No orphan files at this level.
Track-agnostic skills (defumbler, desilencer, captions, gaze, ...) live in `video-creation/skills/`, not here;
this folder holds the track's POLICY on top of them and any processing customization specific to presentations.

| Skill | Doc | Also in the folder | What it does |
|---|---|---|---|
| `desilence/` | `desilence.md` | `desilence_preset.py` | The track's standing silence definition (800 ms min-silence, 300 ms residual between sentences = 200 ms tail + 100 ms head, one zone) pinned in code, wrapping the canonical desilencer: dry-run preview, cut/keep map, swallowed-speech + A/V drift QA. Phase 2. |
| `spotlight/` | `spotlight.md` | `cue_scenes.py`, `spot_common.py`, `render_spotlight.py`, `stitch.py`, `splice.py` (+ the shared renderer `remotion/src/SpotlightPresentation.tsx`) | Phase 4: the deck re-rendered as one container at a time cued to the narration, head/tail kept as filmed, a breath (`chapter_pause`) before every chapter card. Scene spec -> cue resolution against the EDIT word timings + pause planning -> parts render -> sync-safe stitch (pauses' silence inserted there). Fix rounds re-render only the moved windows and splice them into the previous FINAL. |
| `music-bed/` | `music-bed.md` | `music_bed.py` | Format 3 (VS Code coding videos) — the only processing step (also `drone_bed.py`, the SCRIPTED option's drone bed, 2026-11-25): the musical intro from 0:00 (clip gain 0 -> -40 dB), then a random elevator bed from Mike's cue line to the last frame (-32 dB, remix-looped on a bar-aligned region, end-aligned), mixed under the untouched voice, picture stream-copied. |
| `card-overlays/` | `card-overlays.md` | `card_overlays.py` | Format 4 (deck screen share with webcam PiP, free talk): a few overlays inside the deck area (deck cards, chart stills, clips; full-screen only before 2026-10-31), one per moment, cued off the transcript of Mike's enhanced spine. Card pages from the deck's own `<style>` -> region-sized stills -> ONE ffmpeg encode (spotlight entrance, 0.3 s fade out, audio stream-copied, the spine's frame timing) -> contact sheet. No Remotion, no draft. Also in the folder: `html_clip.py` (animated-chart clips), `remux_enhanced.py`, and `cover_runs.py` (the SCRIPTED option: each run of consecutive cover lines as one clip, then the same render + a leak check). |
| `clip-insert/` | `clip-insert.md` | `clip_insert.py` | The SCRIPTED option's clip montage (2026-11-25, longest-bear): `[INSERT]` clips of other people, each with its own voice, spliced into the final spine after a set-up line (`bake` writes the `+clips` spine, its shifted words JSON and `inserts.json`); no names, no captions; cue + cover runs work on the augmented spine. |
| `script/` | `script.md` | `SCRIPT.reference.md`, `script_common.py`, `lint_script.py`, `cue_script.py` | Format 4's SCRIPTED option (v1 2026-11-14, optional, chosen at the start of a video): Mike reads a light `SCRIPT.md`, written like a longform-edited screenplay (2026-11-16): `[COVER]` or `[SCREENSHARE]` spoken lines, a `[SHOW]` line under the `[COVER]` lines naming their card. The format + its gate (Mike's spoken-word rules reused from the longform-edited screenplay lint, never copied), and the cue step that lines the script up with the final spine's word timings: windows, ad-libs, and the NUMBER CHECK (a number said differently from the script). Cover runs + render live in `card-overlays/cover_runs.py`. The optional EXTRAS Mike names in the header (2026-11-15): the vertical cut (`cover_runs.py --vertical`, built), the YT post (the longform-edited `run.py ytpost` by project folder, built), the short (not built on this track yet). |
| `thumbnail/` | `thumbnail.md` | `export_thumb.py` | Series thumbnails as an EDIT of the previous episode's published thumbnail (Higgsfield nano_banana_2, three takes, Mike picks), exported 1920x1080 JPG under YouTube's 2 MB cap. |
