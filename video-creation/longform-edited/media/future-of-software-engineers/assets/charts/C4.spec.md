## The design

One zero line (y 560, x 120-1800, labelled `0% · NO CHANGE`), both bars on one scale (24 px per percentage point): COMPUTER
PROGRAMMERS (`write, modify, and test code...`, BLS's one-line description, cut with an ellipsis because BLS's sentence goes on
"...and scripts that allow computer software and applications to function properly") drops to **-7%** (red: the stylesheet's
negative role; rect x 340, y 560, 220 x 168); SOFTWARE DEVELOPERS, QUALITY ASSURANCE ANALYSTS, AND TESTERS (`design computer
applications or programs`) rises to **+10%** (green: the LIVE bar, the stylesheet-default lit accent; rect x 1000, y 320, 220 x
240). Each name sits on the far side of the zero line from its bar, so the down bar and the up bar read as one diagonal.
Headline `Two jobs, two directions.`; sub-label `Projected, U.S. Bureau of Labor Statistics, 2025 to 2035`.

Arrow: `M572,700 C 800,700 780,402 980,402` (stage px), stroke gradient red -> green 4.5 px, head at (992, 402).

## How to animate (the method)

- Bars grow from the zero line (height 0 -> full, ease out cubic); the dashed slot footprint fades out as its bar starts.
- Values count by whole points with the bar (0 -> -7, 0 -> +10), landing exactly on the cue word; the sign stays fixed.
- The +10% bar's glow fades in over its last 0.2 s.
- The BLS sentence types on character by character (the `BLS` tag first, then the quote), fixed SVG/text positions, no reflow.
- The arrow draws along its path (path length via `getTotalLength` once, then strokeDashoffset), the head pops at the end.
