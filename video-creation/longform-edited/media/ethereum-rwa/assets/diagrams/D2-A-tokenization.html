TOKENIZATION · PLAIN ENGLISH

Take a real asset. Issue it as a token.

REAL ASSET
a treasury bill, a fund, a stock
REGULATED ISSUER
holds the real thing, issues the token
REGULATED
SMART CONTRACT
the token lives onchain, transfers settle in code
TRADEABLE TOKEN
same asset, brand new rails
SETTLES IN MINUTES
TRADES 24/7
PLUGS STRAIGHT INTO DEFI
The asset does not change. The rails do.
Tokenization mechanism · worked example: BlackRock BUIDL, issued via Securitize on Ethereum, March 2024
