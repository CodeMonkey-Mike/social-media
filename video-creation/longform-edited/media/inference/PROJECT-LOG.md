**Opening thesis (every claim verified in DATA.md before it airs):** every AI model is trained ONCE. Everything anyone ever does with it afterwards, every prompt, every transcription, every generated image, is INFERENCE: running the frozen weights against new input. Training is the one-time cost that makes headlines; inference is the recurring cost, the latency the user feels and the part of the system an AI engineer actually operates. If you have ever called a model API, you have done inference. This repo does it hundreds of times a week.

**Pillars (each needs DATA.md facts; the researcher says so if one cannot be sourced from primary material):**
1. **The definition, by contrast.** Training = learning the weights from data, once, expensive. Inference = the frozen weights applied to new input, every request, forever. Over a deployed model's life, inference is where most of the compute and cost accrue (IBM Technology "AI Inference: The Secret to AI's Superpowers" says around 90 percent of a model's life is inference and that serving dwarfs training cost; treat both as "by some estimates", never a hard stat, and find the primary estimate if one exists).
2. **What one LLM request actually does.** Text becomes tokens (the model only sees token IDs; billing is per token). PREFILL reads the whole prompt in parallel and builds the KV cache (compute-bound). DECODE generates one token at a time, each step re-reading the cache (memory-bandwidth-bound, cannot be parallelized across a single request). The two latency numbers people mean: time to first token (prefill) and time per output token (decode). Sources: IBM Technology "What Is LLM Inference? How AI Models Generate Responses" (youtu.be/615-yWyS1n0) and Vishakha Sadhwani "AI Inference CRASH COURSE" (youtu.be/m9D__rxPOl4); confirm each mechanism against a primary source (vLLM docs / the PagedAttention paper / NVIDIA or Hugging Face serving docs).
3. **The levers that make it fast and cheap** (name them, one line each, no deep dive in a 2-minute video): continuous batching, KV / prefix caching, quantization (FP16 to 8 or 4 bit), speculative decoding; the inference engine as the layer between request and GPU (vLLM, SGLang, TensorRT-LLM, Ollama, llama.cpp); hosted API (pay per token) vs self-hosted (pay for the GPU, worth it when the GPU stays busy).
4. **We already do this, every day. OUR OWN CODE as the worked examples (Mike asked for these explicitly; the researcher reads the repo and cites file paths; nothing invented):**
   - SELF-HOSTED inference: `video-creation/shorts/_tooling/whisper_jobs.py` runs OpenAI Whisper (medium) on Mike's RTX 4070 Laptop GPU via CUDA; it loads the model ONCE and decodes every clip window because the model load costs ~20.5 s per process (measured 2026-08-19, in the file's docstring). That is the serving lesson in miniature: keep the weights hot, batch the work. Also `.claude/agents/shared/transcriber.md` (Whisper medium, GPU, word-level) and the track's `scripts/transcribe.py`.
   - HOSTED inference: every headless agent the pipeline spawns (`video-creation/longform-edited/graph/common.py` `spawn_agent` = `claude -p --agent ...`, `linkedin-automation/skills/find-jobs/find_jobs.py` `spawn_reviewer`) is an inference call to Claude, billed per token; a single longform video fires dozens of them (research, screenplay, coverage, music, transitions, comp build, visual QA).
   - Other inference the pipeline buys per call: ChatGPT image generation (`repurpose/`), Higgsfield MIKE-CLONE voice (`video-creation/skills/higgsfield-voice/`), ElevenLabs lip-sync. All inference, none of it training.
   - Mike's question to answer on screen in one line: "do we already do inference?" YES, we have never trained anything; everything this pipeline does with a model is inference.
5. **The 2026 angle the reference videos miss (one line, sourced):** reasoning models spend extra inference-time compute ("thinking" tokens), so the cost of one request now varies with how hard the model thinks; inference, not training, is where that bill lands. Source a primary statement (OpenAI o-series or Anthropic extended-thinking docs, or a Hugging Face / NVIDIA inference-scaling post).
