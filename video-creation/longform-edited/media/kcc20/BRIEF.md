**Opening thesis (to verify in DATA.md):** KCC-20 is Kaspa's first covenant-based fungible token standard, its name a nod to ERC-20. Transfers are enforced by L1 script rules, not by an off-chain indexer. KRC-20 proved demand for tokens on Kaspa; KCC-20 is the attempt to make tokens first-class citizens of the base layer. It just entered its final review window. Real, close, not finished.

**Pillars (each needs DATA.md facts; anything not sourceable from primary material is dropped or softened):**
1. What KCC-20 is: a fungible token spec in the kaspanet/kccs repo (Kaspa Calls for Conventions), made possible by covenants that the Toccata hard fork enabled (deck: Jun 30, 2026). Current status: verify (Last Call per the reference video).
2. How it works, the four ideas: (01) common interface, any wallet, indexer or app can recognize, read and build transfers for a KCC-20 token; (02) extended state, each token can add its own data and behavior on one recognizable surface; (03) flexible authority through KCC-2: a public key, a key commitment, a script, or another covenant can control a token, so covenants can own or govern tokens; (04) Borrowed Receive: every new token UTXO needs KAS under storage-mass rules, Borrowed Receive tops up an existing UTXO instead, owner and KAS value stay put, only the token amount grows.
3. KCC-20 vs KRC-20 (the marquee contrast): origin (Kaspa core contributors, kaspanet/kccs vs Kasplex, a third-party protocol); where balances live (covenant-enforced UTXOs on L1 vs data inscribed on L1 and read by an indexer); who validates (L1 script rules vs the indexer's interpretation); adoption (KRC-20 live since 2024, about 2,153 tokens by July 2026 per the deck vs about 146 KCC-20 tokens so far per a third-party tracker; both [VERIFY], both dated).
4. Where it stands, the timeline: Jun 30 Toccata activates; Jul 15 KCC-20 merged as Draft alongside KCC-1 (covenant layout) and KCC-2 (authority schemes); Aug 22 first implementer flags gaps; Sep 22 Last Call proposed; Oct 1 KCC-1 and KCC-2 hit Last Call; Oct 7 KCC-20 enters Last Call (the newest beat). What Last Call means (final review, about 14 days typical, no fixed end date) and why KCC-20 still cannot go Final before KCC-1 and KCC-2 do. Final technical KCCs today: verify (deck: 0).
