# AI destroying lives: slide state cues

Times are on the FINAL spine (`spine/ALL.e.cut.enhanced.mp4`), taken from COVER-PLAN.json, before any card-pause shift. Each state is a hard swap: shared elements are pixel-identical inside one id, so a swap reads as the row landing. Rows at rest stay muted but readable (the spotlight adds emphasis, it never toggles visibility). The last state of each run holds to the end of its beat.

Theme: DARK, stylesheet default accent (container-canonical.css pasted verbatim, no light or accent file, no chapter_themes). Lit colour = cyan. Accent meaning: green = real / in production, gold = prototype, red = loss / risk, teal = the CodeMonkey Mike brand only. Source + driver: `build_slides.py` (re-run `python build_slides.py [id ...]` to rebuild).

C19-1/2/3 use the `elegant-promo-2022` theme's own look (Roboto, teal-to-blue bar, magenta discs), settled state per `library.json` devices `ep-disc-sweep` + `ep-label-title`. `C19-n.png` = the settled full frame over its IMG plate; `C19-n-overlay.png` = the same discs + bar + title + sub-line on transparent, for the comp to lay over its own pushing-in plate while it runs the device motion (iris / circle burst, disc sweep, bar wipe, title tracking).
