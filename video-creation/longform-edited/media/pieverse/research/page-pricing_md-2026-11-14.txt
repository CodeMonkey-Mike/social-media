# Pieverse pricing

Currency: USD
Billing period: month

## Purr-Fect Claw tiers

### Starter
- Plan ID: starter
- Price: $10/month
- AI credits included: 0
- Default model: pieverse/auto/free
- Description: Always-on agent on the free model, or plug in your own API key.
- Limits:
  - Free LLM (rate limited)
  - Bring your own API key
  - Up to 1 vCPU / 2 GB RAM

### Basic
- Plan ID: basic
- Price: $29/month
- AI credits included: 100
- Default model: pieverse/auto/paid
- Description: A personal agent with included credits for everyday chats.
- Limits:
  - 100 AI credits/mo included
  - Up to 2 vCPU / 4 GB RAM

### Standard
- Plan ID: standard
- Price: $49/month
- AI credits included: 150
- Default model: pieverse/auto/paid
- Description: Daily companion with more credit and memory headroom.
- Limits:
  - 150 AI credits/mo included
  - Up to 2 vCPU / 6 GB RAM

### Pro
- Plan ID: pro
- Price: $99/month
- AI credits included: 600
- Default model: pieverse/auto/paid
- Description: Heavy usage with a larger credit budget and more compute.
- Limits:
  - 600 AI credits/mo included
  - Up to 4 vCPU / 8 GB RAM

### Ultra
- Plan ID: ultra
- Price: $279/month
- AI credits included: 2000
- Default model: pieverse/auto/paid
- Description: Maximum compute and credit budget for demanding workloads.
- Limits:
  - 2,000 AI credits/mo included
  - Up to 6 vCPU / 16 GB RAM

## Payment methods
- Crypto-native checkout for product purchases and renewals.
- Invoice and on-chain payment surfaces exist for human-authenticated flows.
- Live autonomous agent payment protocols are not public or advertised as executable today.

## Enterprise and custom
Contact hello@pieverse.io for custom agent, wallet, skill, compliance, or enterprise deployment needs.

## Current limitations
- Pricing docs do not expose live autonomous agent payment actions.
- x402, UCP, ACP, and AP2-style transaction protocols are deferred for public agent execution.
