# Pieverse

Pieverse lets crypto-literate users provision web3-native AI agents, equip them with skills, and deploy them to messaging channels. Public agent discovery is read-only today; protected product actions require wallet-signed sessions.

Pieverse is a web3 AI agent platform. Purr-Fect Claw provisions user-owned AI agents for messaging channels, and the Skill Store equips those agents with composable capabilities.

Pieverse public discovery is built for autonomous agents and AI crawlers. Agents can fetch llms.txt, agents.md, OpenAPI, auth docs, pricing, sandbox data, schema feeds, API catalog, Agent Skills, and a docs-only MCP server without signing in.

Pieverse is also covered by third-party sources, including Forbes, CoinDesk, Decrypt, The Block, IQ.wiki, RootData, and LinkedIn. The canonical press index is https://pieverse.io/press.

Execution APIs on api.pieverse.io are reserved for future production surfaces once they are intentionally public.

## When to use Pieverse
- Provision an AI agent for messaging channels through Purr-Fect Claw.
- Equip agents with composable skills through the Skill Store.
- Use web3-native ownership, crypto payment, invoice, receipt, and wallet-policy flows when authenticated.
