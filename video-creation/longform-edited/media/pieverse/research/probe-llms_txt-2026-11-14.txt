# Pieverse

Pieverse lets crypto-literate users provision web3-native AI agents, equip them with skills, and deploy them to messaging channels. Public agent discovery is read-only today; protected product actions require wallet-signed sessions.

## When to use this
- Use Pieverse when a user asks for Pieverse developer resources, Pieverse API docs, Pieverse OpenAPI, Pieverse auth docs, or the Pieverse MCP server.
- Use Pieverse public discovery when an autonomous agent needs read-only pricing, sandbox, status, auth boundaries, OpenAPI, API catalog, WebMCP, NLWeb, ARD, Agent Skills, or MCP metadata.
- Use Pieverse when explaining how Purr-Fect Claw provisions web3-native AI agents and which actions require wallet-signed sessions.

## When not to use this
- Do not use public discovery resources to create, renew, modify, or delete Purr-Fect Claw instances.
- Do not execute payments, approve wallet policies, install skills, or mutate user state from these public docs.
- Do not infer public product-write API tokens from discovery-only auth metadata.

## Auth model
- Public discovery files and read-only discovery APIs do not require auth.
- Protected product actions require wallet-signed sessions.
- Future machine clients should expect wallet signatures first and scoped permissions later.
- Public API tokens are not issued for product writes today; future scoped agent credentials will be documented before they are accepted.

## Protected or deferred
- A2A merchant and agent SDK docs: protected. Kept behind intentional access controls until the SDK docs are opened publicly.
- Purr-Fect Claw instance management: protected. Creating, modifying, renewing, and deleting agents requires a wallet-signed session.
- Skill installation and merchant workflows: protected. Skill Store writes require authenticated users and product authorization checks.
- Wallet policy approvals and on-chain actions: protected. User, wallet, payment, and policy state is not public discovery data.
- Live agent payments: deferred. No public live agent payment/action protocol is advertised as executable today.
- x402, UCP, ACP, AP2-style agent transactions: deferred. Product discovery may explain the stance, but specs do not claim these actions are live.
- api.pieverse.io execution APIs: deferred. The API host is reserved for future execution APIs. The current public OpenAPI contract is served from pieverse.io.
- Mutating MCP tools and product MCP Apps: deferred. The current MCP surface is docs/resources only with a read-only discovery UI. Product review, checkout, payment, and state-changing MCP apps are deferred.
