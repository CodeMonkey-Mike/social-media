Use this page when searching for Pieverse API docs, Pieverse OpenAPI, Pieverse auth docs, the Pieverse MCP server, llms.txt, agents.md, Agent Skills, or public resource catalogs.

## Auth and boundaries
- Pieverse auth docs: https://pieverse.io/auth.md
- OAuth protected resource metadata: https://pieverse.io/.well-known/oauth-protected-resource

- OAuth authorization server metadata: https://pieverse.io/.well-known/oauth-authorization-server

- Agent auth register markdown: https://pieverse.io/agent/auth/register.md
- Sandbox: https://pieverse.io/sandbox.md
- Public discovery is unauthenticated and read-only.
- Protected product writes require wallet-signed sessions.
- Mutating agent tools, live autonomous payments, and protected A2A SDK docs are not public surfaces.
- Future protected write APIs should require Idempotency-Key on retryable create, renewal, invoice, payment, and wallet-policy operations.
