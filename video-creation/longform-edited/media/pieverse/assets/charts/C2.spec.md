## How to animate (the method)

- Draw the FULL series once as one static SVG path (+ its area fill, gradient green .26 -> 0). Reveal it with a clipPath
  rect whose right edge is `x(headTime)`; NEVER rebuild the path per frame (no re-raster jitter, charts.md section 6).
  Speed is linear in DATE (not path length), eased per segment.
- A head dot (r 7, `#00e68a`, soft halo) rides the line at the clip edge: interpolate y between the two points around
  `headTime` from `points[]`.
- Marker landing: ring pops scale 0 -> 1.15 -> 1 (0.3 s) with a halo (r 22, green .20); its dashed leader draws from the
  dot to the callout (0.25 s); the callout fades in + rises 8 px (0.35 s) LIT (green border + glow). When the next marker
  lands, earlier rings + callouts settle to REST (.5 to .55 opacity) over 0.3 s.
- Leaders (exact, from `callouts`): ATL = left to the gutter x 250, up, right into its box (it never crosses the
  launch-week spikes); Upbit = straight up; ATH = straight left.
