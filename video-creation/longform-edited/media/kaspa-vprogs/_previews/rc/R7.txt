Docker quickstart
Run the latest Rusty Kaspa image

Exposes gRPC on port 16110 so you can talk to the node from your dev machine. Ephemeral container — no persistent storage or inbound P2P.

$
docker run -d --name kaspad -p 16110:16110 kaspanet/rusty-kaspad:latest

DEVELOPMENTS

Follow the work in public

Separate the consensus capabilities live on mainnet from the builder tooling and research that are still evolving.

Channel
Live discussion
Core R&D Telegram

The main public stream for current Kaspa research and development discussions. Discord is still used, but most core discussion now happens here.

Forum
Kaspa Research

Long-form forum for protocol, consensus, economics, and mining discussion, plus KIP drafts and proposals.

Community
Kas Smiths: builders' workshop

Discuss and refine Kaspa standards, protocols, tooling, shared infrastructure, and product ideas with other builders.

Live on mainnet
Toccata programmability

Toccata added programmable UTXOs to Kaspa through covenants, transaction introspection, ZK verification, and sequencing support for based apps. It has been live on mainnet since June 30, 2026.

Covenant tooling
Silverscript

The primary higher-level authoring path for mainnet covenants, compiling to native Kaspa Script. Tooling is still early; check current release and audit status before production use.

In construction
vProgs: Based Apps

The shared-state application path is under construction. The vProgs runtime is an evolving source of patterns, not yet a stable external developer API; Full vProgs remain a future direction.

SDK
Python SDK

In beta and nearly complete. Python tooling is progressing in the open and expanding the developer surface.

Protocol
KIPs

Track proposals that can change how applications and infrastructure integrate with the network.
