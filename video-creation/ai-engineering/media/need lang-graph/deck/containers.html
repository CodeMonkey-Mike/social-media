LangGraph · the engine
The graph you draw is the program
g = StateGraph(State) g.add_node("transcribe", transcribe) g.add_node("clip", clip) g.add_edge("transcribe", "clip") app = g.compile()
Nodes, edges, one shared state. Add node, add edge, compile.

The Pattern Has a Name
Fan-out, then fan-in
Fan-out
One input splits into parallel branches. Each runs on its own.
Fan-in
The branches converge back to one point. Textbook distributed systems.

LangGraph speaks this pattern natively.

The Shared State
One typed object, one field per thing
class State(TypedDict): batch_id: str transcript: str clips: list[Clip] draft_queue: list[Post]
Every node reads and writes this same object as it flows through the graph.
Fan-out · the Send API
The trick is all in the return line
from langgraph.types import Send def fan_out_clips(state): # a routing function return [Send("caption_clip", {"clip": c}) for c in state["clips"]] g.add_conditional_edges("transcribe", fan_out_clips)
A routing function returns a LIST of Send objects, one per clip. Each spawns its own parallel worker.
Fan-in · reducers
One annotation does the merge
class State(TypedDict): clips: list[Clip] captions: Annotated[list, operator.add] # append, don't overwrite
Twenty workers write back without stomping on each other. The fan-in handles itself.

A Design Rule Worth Stealing
Peers never spawn peers

Only the orchestrator owns the graph. Workers do their job and report back. That one rule keeps the whole thing acyclic and sane.

What It Costs You In Code
Wrap a file, and no SQL
import sqlite3 from langgraph.checkpoint.sqlite import SqliteSaver conn = sqlite3.connect("checkpoints.db", check_same_thread=False) saver = SqliteSaver(conn) app = g.compile(checkpointer=saver)
Every node run is now checkpointed automatically. Keep a JSON registry alongside if you want.

Retry Policies · Per Node
Posting gets zero retries
from langgraph.pregel import RetryPolicy g.add_node("post", post_node, retry_policy=RetryPolicy(max_attempts=1))
download → 3  ·  render → 2  ·  post → 0. "At least once" is wrong for a public action.
