The livestream graph · the step that builds each short

One Agent Became Four Steps

Before
remotion-builder
plans the imagesgenerates them in the browserchecks its own imagesbuilds the video
1 agent, 1 run per short
Now
1 · PLAN
remotion-builder
Writes the plan and a JSON list of the images to make. Then it stops.
→
2 · IMAGESNEW
image-gen
Generates every image on the list.The graph's code holds the browser lock.
→
3 · IMAGE CHECK
visual-qa
Opens every image. Reports PASS or FAIL and changes nothing.
→
4 · BUILD
remotion-builder
Builds the video from the files on disk.
FAIL: back to image-gen with the checker's report, 2 rounds at most
4 steps, 3 agents per short. The same builder is called twice, and it never touches the browser.
Source: batch_graph.py, the per-clip build pipeline, read Nov 19, 2026.
