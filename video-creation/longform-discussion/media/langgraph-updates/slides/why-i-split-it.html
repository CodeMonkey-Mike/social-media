Why the build step was rebuilt

Three Problems With One Agent Doing It All

The one-agent build
What changed

It waited for the browser, and a waiting agent can quit

One browser, one image at a time. A builder once ended its turn while it waited, and the run sat there.

→

The lock moved into code

The graph takes the lock, starts the image agent, and releases it in a finally block.

It checked its own images

No second pair of eyes saw a short's images before the video was built.

→

A separate agent checks every image

It only reports: PASS or FAIL, the defect, and the fix for the prompt.

Mechanical work ran on the builder's model

Image generation ran inside the builder: opus, xhigh effort.

→

The image agent runs on a smaller model

sonnet, xhigh effort. The builder keeps its model for the video code.

One agent per decision. Where nothing is being decided, it's code.
